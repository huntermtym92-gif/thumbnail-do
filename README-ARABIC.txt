طريقة الحصول على ملف APK (بدون تثبيت أي برامج، تحتاج حساب GitHub مجاني)
=======================================================================

1) افتح github.com وسجّل حساب مجاني.
2) اضغط علامة + (أعلى الصفحة) ثم New repository.
   اكتب أي اسم (مثلاً thumbnail-maker) ثم Create repository.
3) في الصفحة الجديدة اضغط "uploading an existing file".
   افتح المجلد بعد فك الضغط، وحدّد كل الموجود داخله ما عدا هذا الملف README،
   (مجلد app + ملفات build.gradle و settings.gradle و gradle.properties)
   واسحبها كلها على الصفحة. استنى ما ترفع، ثم اضغط Commit changes.
4) مهم: ملف البناء. اضغط Add file ثم Create new file.
   في خانة الاسم اكتب بالظبط:   .github/workflows/build.yml
   (لما تكتب الشرطة المائلة / هيعمل مجلدات لوحده)
   افتح الملف WORKFLOW-build.yml.txt وانسخ كل اللي فيه والصقه في الصفحة، ثم Commit changes.
5) اضغط تبويب Actions. هتلاقي عملية اسمها Build APK شغالة.
   استنى 3 – 6 دقايق لحد ما تظهر علامة ✓ خضراء.
6) افتح العملية، انزل لقسم Artifacts، اضغط thumbnail-maker-apk لتنزيل ملف zip.
   فك الضغط هتلاقي app-debug.apk.
7) ابعته لموبايلك وثبّته (هيطلب السماح بتثبيت تطبيقات من خارج المتجر).

لو ظهرت علامة ✗ حمراء في Actions: افتح العملية، انسخ آخر سطور الخطأ وابعتها لي.
الصور بتتحفظ في معرض الصور داخل مجلد ThumbnailMaker.
